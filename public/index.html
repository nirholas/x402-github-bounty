x402-github-bounty

Fund a GitHub issue and get a signed certificate back in the same response. Anyone can then buy a verification report built from live GitHub state — did it close, which merged PRs reference it. Non-custodial: the money never touches this service.

Try it

Look at the challenge before paying anything:

curl -s -X POST http://localhost:4027/bounties | jq '.accepts[0].outputSchema'

Then let a wallet answer it. x402-fetch wraps fetch, catches the 402, signs, and retries — the paid body lands in the same call:

import { wrapFetchWithPayment } from "x402-fetch";
import { privateKeyToAccount } from "viem/accounts";

const pay = wrapFetchWithPayment(fetch, privateKeyToAccount(process.env.PRIVATE_KEY));
const res = await pay("http://localhost:4027/bounties", {
  method: "POST",
  headers: { "content-type": "application/json" },
  body: JSON.stringify({
    issueUrl: "https://github.com/nodejs/node/issues/1",
    amount: 250,
    funder: "agent@example.com",
  }),
});
console.log(await res.json());
